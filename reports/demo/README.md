## Что стоит проверить человеку

Агент указывает уверенность для каждой находки. Перед передачей разработчикам эти пункты стоит подтвердить вручную:

* **Пустая витрина Haval** (`/online-stock`, уверенность 50%): за 10+ секунд не появилось ни одного авто. Возможно, виджет склада не отвечает на запросы из-за рубежа: прогон шёл из облака. Проверить из РФ.
* **Скорость конкурентов** (LCP 13–16 с): замер лабораторный, через сетевой прокси. Порядок цифр для своих сайтов стабилен между прогонами, а для «преимущества в скорости» лучше подтвердить через PageSpeed.
* **Портал alyans-auto.ru** в демо не включён. После нескольких прогонов подряд сайт стал показывать агенту Yandex SmartCaptcha, и агент, как и задумано, отказался делать выводы о контенте. Из того, что проверяется по HTTP и от капчи не зависит, агент нашёл **P0-ошибку: robots.txt портала указывает sitemap чужого сайта** (`https://cheby-alyans.ru/sitemap.xml`). Для регулярного аудита IP агента нужно добавить в белый список.

## Повторный прогон

Повторный запуск в ту же папку `reports/` добавит в отчёт блок «Изменения с прошлого прогона» (исправлено / новое / осталось) и начнёт считать «зависшие» карточки авто по `inventory.json`.
